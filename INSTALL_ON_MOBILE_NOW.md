### Step 3: Install on Mobile

1. **Tap the APK file** you downloaded
2. **Allow installation from unknown sources** if prompted:
   - **Android 8.0+**: 
     - Settings → Apps → Install Unknown Apps
     - Enable for your browser (Chrome/Firefox)
   - **Android 7.0 and below**:
     - Settings → Security → Unknown Sources → Enable

3. **Tap "Install"**
4. **Wait for installation** (may take 30-60 seconds)
5. **Tap "Open"** or find "Secure Wallet" in your app drawer
